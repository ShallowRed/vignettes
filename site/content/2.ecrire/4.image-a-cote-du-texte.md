## Téléverser l'image

Dans l'éditeur du studio, collez l'image (Ctrl + V, ou Cmd + V sur Mac), glissez son fichier dans le texte, ou choisissez « Téléverser une image » dans le menu « Insérer » de la barre d'outils pour sélectionner le fichier sur votre ordinateur. Le studio téléverse l'image et insère un bloc `Image` à l'endroit du curseur :

```mdc
::Image{src="/media/3f9a….png" alt=""}
::
```

L'image pèse 10 Mo au plus, aux formats PNG, JPG, WEBP, GIF, SVG ou AVIF. La valeur de `src` est l'adresse de l'image dans le studio.

## Placer l'image à droite du texte

1. Copiez la valeur de `src`, puis supprimez le bloc `Image`.
2. Dans la barre d'outils, choisissez « Média + texte » dans le menu « Modèles ». Le studio insère, après la ligne du curseur, une diapositive avec un titre, une annotation `:layout{name="media-right" …}` et un paragraphe.
3. Remplacez l'adresse de `src` par l'adresse copiée, puis écrivez le titre, la description de l'image dans `alt` et le texte de la diapositive.

Dans une diapositive déjà écrite, écrivez l'annotation `:layout` sous le titre, avec la mise en page `media-right` et l'adresse copiée dans `src`.

::deck-example
```mdc
### Le catalogue

:layout{name="media-right" src="/images/studio/catalogue.png" fit="contain"}

Le catalogue range les présentations par dossier.

Le bouton « Nouvelle présentation » ouvre la fenêtre de création.
```
::

`fit="contain"` affiche l'image entière dans son panneau. Avec `fit="cover"`, la valeur par défaut, l'image remplit le panneau et ses bords peuvent être coupés.

## Choisir une autre disposition

- `media-left` place l'image à gauche du texte.
- `media-right-wide` et `media-left-wide` donnent plus de largeur à l'image.
- `media-below` place l'image sous le titre, sur toute la largeur.
- `lightbox="true"` agrandit l'image au clic.

La page [La syntaxe](/ecrire/syntaxe#les-mises-en-page) décrit toutes les mises en page et leurs réglages.
