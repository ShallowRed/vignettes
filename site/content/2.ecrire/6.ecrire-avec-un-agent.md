---
title: Écrire avec un agent
description: Installer le plugin vignettes-decks dans Claude Code, faire écrire une présentation dans n'importe quel projet, puis l'importer dans le studio.
---

Le plugin `vignettes-decks` contient les règles d'une présentation Vignettes pour Claude Code : l'en-tête, le découpage, les annotations, les composants et les stories Storybook. Avec lui, vous demandez une présentation depuis le dépôt de votre produit, où l'agent lit le code, la documentation et les stories ; il écrit un fichier `.md`, que vous importez dans le studio.

## Installer le plugin

Le plugin est publié dans le dépôt privé `ShallowRed/vignettes`. Votre compte GitHub doit pouvoir le lire, et votre ordinateur le cloner sans saisie de mot de passe : par une connexion `gh auth login`, ou par une clé SSH sans phrase de passe, avec `github.com` dans `known_hosts`.

Dans une session Claude Code :

```text
/plugin marketplace add ShallowRed/vignettes
/plugin install vignettes-decks@vignettes
```

Choisissez « Install for you (user scope) » pour l'utiliser dans tous vos projets. Après l'installation, la liste des commandes, ouverte par `/`, contient `/vignettes-decks:writing-decks`. La page [Install and manage plugins](https://code.claude.com/docs/en/discover-plugins#add-a-private-marketplace) de Claude Code décrit l'accès à une marketplace privée.

## Faire écrire la présentation

Ouvrez Claude Code dans votre projet et demandez la présentation en nommant Vignettes :

```text
Écris une présentation Vignettes de six diapositives pour la revue de sprint, thème dsfr, dans docs/presentations/revue-de-sprint.md.
```

Pour être sûr que l'agent lise les règles du plugin, commencez la demande par `/vignettes-decks:writing-decks`. Pour des écrans de votre Storybook, donnez-lui l'adresse du Storybook et le nom des composants ([Intégrer une story](/ecrire/story-storybook)).

## Importer le fichier

Dans le catalogue, cliquez sur « Nouvelle présentation », choisissez le point de départ « Fichier Markdown », puis déposez le fichier. Le titre et le thème viennent de l'en-tête du fichier, qui doit contenir la clé `title`. Si une clé a une valeur refusée, le message nomme la clé : corrigez le fichier, puis choisissez-le de nouveau.

La présentation créée est privée, et indépendante du fichier. Relisez-la dans l'aperçu, puis [publiez-la](/demarrer/premiere-presentation#publier-et-partager).

## Faire modifier une présentation

1. [Téléchargez son texte](/ecrire/presenter#télécharger-le-texte) et placez le fichier dans votre projet.
2. Demandez la modification à l'agent.
3. Dans l'éditeur, remplacez tout le texte par celui du fichier modifié, puis publiez. La version précédente reste dans l'[historique](/studio/versions-et-brouillon#lhistorique).

Pour garder la présentation d'origine, importez le fichier modifié comme une nouvelle présentation.
