Une présentation est un texte Markdown en deux parties : un en-tête entre deux lignes `---`, puis le texte des diapositives. Chaque exemple de cette page montre la présentation au-dessus de son texte.

## L'en-tête

L'en-tête contient les réglages de la présentation, une ligne `clé: valeur` par réglage.

```yaml
---
title: Bilan du mois
theme: dsfr
lang: fr
parser: separator
---
```

- `title` : le titre de la présentation, dans le catalogue et dans l'onglet du navigateur.
- `theme` : le thème visuel, parmi ceux de votre studio.
- `lang` : la langue du texte. Avec `fr`, la valeur par défaut, le texte suit la typographie française : espace fine insécable avant `:`, `;`, `?` et `!`, et dans les guillemets.
- `parser` : la règle de découpage des diapositives, `separator` par défaut ou `heading` (voir [Découper les diapositives](#découper-les-diapositives)).
- `storybook` : l'adresse du Storybook dont la présentation affiche des stories (voir [Intégrer une story](/ecrire/story-storybook)).
- `reveal` : les réglages d'affichage de reveal.js, comme la taille des diapositives, la numérotation et les transitions.

Dans l'éditeur, Ctrl + Espace dans l'en-tête liste les réglages, avec leur description et leur valeur par défaut.

## Découper les diapositives

Avec `parser: separator`, une ligne `---` commence une nouvelle diapositive, et une ligne `----` une diapositive verticale, rangée sous la précédente. Le public avance avec la flèche droite ; vous descendez dans les diapositives verticales avec la flèche bas, pour une question ou un détail.

::deck-example
```mdc
# Le titre de la présentation

---

### Une diapositive

Le public suit les diapositives de gauche à droite.

----

### Une diapositive verticale

Un détail, pour répondre à une question.

---

### La diapositive suivante
```
::

Avec `parser: heading`, les titres découpent le texte : `#` ouvre la diapositive de titre, `##` une diapositive, et `###` une diapositive verticale sous la précédente. Une ligne `---` découpe aussi.

::deck-example
```mdc
---
parser: heading
---

# Le titre de la présentation

## Une diapositive

Le public suit les diapositives de gauche à droite.

### Une diapositive verticale

Un détail, pour répondre à une question.

## La diapositive suivante
```
::

Une ligne `---` ou un titre placé dans un bloc de code ou dans un composant ne découpe pas le texte.

Avec les deux règles, une diapositive `##` réduite à son titre et à un paragraphe de 140 caractères au plus est une section : le thème l'affiche sur un fond de couleur, bleu avec le thème DSFR. Avec plus de contenu, une liste, un composant ou une annotation `:layout`, elle a la mise en page d'une diapositive de contenu.

## Les annotations

Une annotation est une ligne `:nom{…}` qui règle la diapositive où elle se trouve, sans apparaître dans son texte.

- `:pretitle{text="…"}` : un texte au-dessus du titre.
- `:subtitle{text="…"}` : un texte sous le titre.
- `:slide-background{image="…"}` : une image en fond de diapositive.
- `:quicklink{text="…" href="…"}` : un lien épinglé en bas de la diapositive.
- `:layout{name="…"}` : la mise en page de la diapositive, décrite ci-dessous.

::deck-example
```mdc
### Les résultats du trimestre

:pretitle{text="Partie 2"}
:subtitle{text="Chiffres arrêtés au 30 septembre"}
:quicklink{text="Le tableau de bord" href="https://example.com"}

Le nombre de demandes traitées a doublé.
```
::

## Les mises en page

Les mises en page `media-*` partagent la diapositive entre le texte et un média, image ou page web, dont `src` donne l'adresse :

- `media-right` et `media-left` : le média à droite ou à gauche du texte ;
- `media-right-wide`, `media-left-wide` : un média plus large ;
- `media-right-xwide`, `media-left-xwide` : un média qui réduit le texte à une colonne de légendes ;
- `media-below` et `media-above` : le média sous ou au-dessus du titre, sur toute la largeur ;
- `media-cover` : le média sur toute la diapositive, avec le titre sur un cadre translucide.

Deux mises en page gardent la diapositive pour le texte : `grid-compact` réduit le titre à une ligne, et `full` affiche le texte en un seul bloc.

::deck-example
```mdc
### Le parcours

:layout{name="media-right" src="/images/placeholder.svg" fit="contain"}

Trois étapes, du dépôt de la demande à la réponse.
```
::

Les autres réglages de `:layout` :

- `type` : `image` ou `iframe`. Sans `type`, une adresse qui finit par une extension d'image, comme `.png`, donne une image, et toute autre adresse une page web.
- `fit` : `cover`, par défaut, remplit le panneau quitte à couper les bords de l'image ; `contain` affiche l'image entière.
- `lightbox="true"` : le média s'ouvre en plein écran au clic.
- `alt` : la description de l'image pour les personnes qui ne la voient pas.
- `story` : l'identifiant d'une story Storybook, affichée dans le panneau du média (voir [Intégrer une story](/ecrire/story-storybook#afficher-une-story)).
