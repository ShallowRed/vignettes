## Écrire les notes

Dans la diapositive, écrivez le texte des notes dans un bloc `Notes`. Vous pouvez placer le bloc n'importe où dans la diapositive ; le public ne le voit pas.

::deck-example
```mdc
### Les délais de traitement

Quinze jours en moyenne, contre vingt et un l'an dernier.

::Notes
- Le délai est compté du dépôt à la réponse.
- Rappeler que deux agents ont rejoint l'équipe en mars.
::
```
::

Les notes acceptent le Markdown : listes, gras, liens.

## Lire les notes pendant la présentation

1. Ouvrez la présentation avec le bouton « Présenter » de l'éditeur.
2. Appuyez sur la touche S, ou cliquez sur « Vue conférencier » dans la barre de commandes, en haut à droite.
3. Une nouvelle fenêtre affiche la diapositive en cours, la diapositive suivante, un chronomètre et les notes.

Les deux fenêtres restent synchronisées : changer de diapositive dans l'une change de diapositive dans l'autre. Si aucune fenêtre ne s'ouvre, autorisez les fenêtres pop-up pour l'adresse du studio dans votre navigateur.
