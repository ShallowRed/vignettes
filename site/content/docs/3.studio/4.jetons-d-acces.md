---
title: Jetons d'accès
description: Créer un jeton pour qu'un script, un agent ou la ligne de commande lise et publie des présentations avec les droits de votre compte, et le révoquer.
---

Un jeton d'accès authentifie un script, un agent ou la ligne de commande auprès du studio, avec les droits de votre compte : il ouvre et modifie les présentations que votre compte ouvre et modifie, au plus comme un compte Éditeur. Un changement de vos droits vaut aussi pour le jeton, dès la requête suivante.

Vous créez un jeton depuis le menu de votre compte, « Jetons d'accès », avec :

- un nom qui dit où il sert, comme « CLI MacBook » ou « Publication CI » ;
- une portée, « Lecture », ou « Lecture et publication » pour créer, enregistrer et publier ;
- une durée de 30, 90 ou 365 jours.

Le jeton est affiché une seule fois. Rangez-le aussitôt dans le gestionnaire de secrets du script ou de la CI, ou dans le trousseau de votre ordinateur. Un script l'envoie dans l'en-tête `Authorization` :

```bash
curl -H "Authorization: Bearer $VIGNETTES_TOKEN" https://vignettes.example.org/api/presentations/ma-presentation/markdown
```

La page « Jetons d'accès » liste vos jetons, avec leur dernière utilisation et leur date d'expiration. Révoquez un jeton dès qu'une autre personne a pu le lire, après l'avoir collé dans un message par exemple : les requêtes qui le portent sont refusées aussitôt. Un Propriétaire peut révoquer tous les jetons d'un compte depuis la page « Comptes ».
