description: Écrire un titre, un paragraphe, une liste, du gras, un lien et une image en Markdown, le format du texte d'une présentation.
---

Une présentation Vignettes est un texte écrit en Markdown. Le Markdown est du texte ordinaire, avec quelques signes qui donnent la mise en forme : pour un titre, vous écrivez un `#` en début de ligne ; pour du gras, deux `*` de chaque côté du mot. Vous écrivez ces signes au clavier, et le studio affiche le résultat dans l'aperçu.

Chaque exemple de cette page affiche une diapositive au-dessus de son texte. Le texte d'un exemple est celui que vous écrivez dans l'éditeur du studio.

## Un titre et un paragraphe

Une ligne qui commence par `###` suivi d'une espace est le titre de la diapositive. Les lignes qui suivent forment un paragraphe. Une ligne vide sépare deux paragraphes.

::deck-example
```mdc
### Ce qui est en ligne

La page d'accueil est en ligne depuis lundi.

Le formulaire de contact suit la semaine prochaine.
```
::

Le nombre de `#` donne le niveau du titre. Dans une présentation, vous écrivez avec `#` le titre de la première diapositive, avec `##` celui d'une diapositive de section, quand elle contient son titre et au plus une ligne courte, et avec `###` celui d'une diapositive de contenu. La page [La syntaxe](/ecrire/syntaxe) décrit ces niveaux.

## Une liste

Une ligne qui commence par `-` et une espace est un élément d'une liste à puces. Une ligne qui commence par un nombre suivi d'un point, `1.`, est un élément d'une liste numérotée.

::deck-example
```mdc
### Les étapes

- La page d'accueil
- Le formulaire de contact

1. Recueillir les besoins
2. Tester avec cinq usagers
3. Mettre en ligne
```
::

## Du gras, de l'italique et un lien

Pour du gras, vous écrivez deux `*` de chaque côté du mot, et pour de l'italique, un seul `*`. Pour un lien, vous écrivez le texte du lien entre crochets, puis l'adresse entre parenthèses.

::deck-example
```mdc
### Le suivi de la demande

La demande est **acceptée** depuis *mardi*.

Le détail est sur [le site du service](https://www.service-public.fr).
```
::

## Une image

Pour une image, vous écrivez un lien précédé d'un `!`. Le texte entre crochets décrit l'image pour les personnes qui ne la voient pas ; l'adresse entre parenthèses est celle du fichier.

::deck-example
```mdc
### Le catalogue

![Le catalogue du studio, avec le dossier Équipe produit](/images/studio/catalogue.png)
```
::

L'adresse de cet exemple est celle d'une image du site de documentation. Dans le studio, pour une image de votre ordinateur, choisissez « Téléverser une image » dans le menu « Insérer » : le studio téléverse l'image et insère un bloc `Image` avec son adresse. La page [Placer une image à côté du texte](/ecrire/image-a-cote-du-texte) décrit ce téléversement.

## Pour continuer

Dans l'éditeur du studio, la barre d'outils au-dessus du texte insère ces signes pour vous : sélectionnez un mot, puis cliquez sur le bouton du gras, de la liste ou du lien.

La page [La syntaxe](/ecrire/syntaxe) décrit ce que Vignettes ajoute au Markdown : l'en-tête de la présentation, le découpage en diapositives et les annotations.
