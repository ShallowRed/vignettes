# Bilan de l'atelier

*Équipe produit, novembre 2026*

## Un texte court

- Trois équipes ont essayé l'éditeur
- Deux semaines d'essai

## Un texte trop long

- Les participantes ont créé leur première présentation en moins de dix minutes
- L'import d'un fichier Markdown existant a servi à deux équipes sur trois
- Le panneau « Mise en page » a été ouvert par toutes les équipes dès la première séance
- Les modèles de diapositive ont remplacé la copie d'une présentation précédente
- La publication a demandé une explication sur la différence avec le brouillon
- Le partage par lien a été préféré à l'invitation par adresse
- Les notes de présentation ont été découvertes par une seule équipe
- L'export en PDF a servi pour l'envoi du compte rendu aux partenaires
- La vue plan a aidé à réordonner les diapositives avant la restitution
- Les images ont été ajoutées par glisser-déposer depuis le bureau
- Les thèmes ont été changés une fois, au début, puis laissés tels quels
- La recherche dans le catalogue a servi à retrouver les présentations de l'atelier
- Les commentaires oraux ont porté surtout sur la taille du texte à côté d'une image
- Une équipe a demandé un mode de présentation avec minuteur
